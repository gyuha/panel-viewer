# Panel Viewer

로컬 코믹 아카이브(cbz/cbr/zip)를 읽는 Tauri 기반 데스크탑 이미지 뷰어.

## Language

**코믹 아카이브 (Comic archive)**:
이미지들을 담은 압축 파일 하나. cbz(zip), cbr(rar), 일반 zip 세 종류를 지칭한다.
_Avoid_: 책, 만화 파일, 압축 파일

**페이지 (Page)**:
아카이브 안의 이미지 한 장. 아카이브 내 항목명의 자연 정렬(natural sort) 순서가 곧 페이지 순서다.
_Avoid_: 이미지, 컷

**커버 (Cover)**:
아카이브의 첫 페이지. 파일 패널의 썸네일로 쓰인다.

**보기 모드 (View mode)**:
페이지를 표시하는 두 가지 방식 — 한 장씩 보는 페이지 모드(`한장`)와 연속 스크롤 모드(`연속`). (좌→우/우→좌 읽기 방향 구분은 제거됨.)
_Avoid_: 읽기 방향, 좌→우/우→좌 모드

**미리보기 (Preview)**:
파일 패널에서 파일을 클릭하면 뷰어가 그 파일을 즉시 여는 것. 별도의 미리보기 패널이나 열기 단계는 없다. 목록의 커버 썸네일이 유일한 열기 전 미리보기다.
_Avoid_: 상세 패널, 퀵룩

**파일 패널 (File panel)**:
왼쪽 패널. 현재 폴더의 하위 폴더와 코믹 아카이브를 평평한 목록으로 보여준다. 폴더 트리가 아니며, 폴더를 클릭하면 그 폴더의 목록으로 이동한다.
_Avoid_: 폴더 트리, 탐색기 트리, 사이드바(레이아웃 위치일 뿐)

**현재 폴더 (Current folder)**:
파일 패널이 보여주는 폴더이자 이전/다음 파일 이동의 범위. 앱이 단일하게 관리하는 하나의 상태다. 파일을 어떤 경로(파일 연결·다이얼로그·드래그·패널 클릭)로 열든 현재 폴더는 그 파일이 있는 폴더로 바뀐다.
_Avoid_: 작업 폴더, 형제 목록(현재 폴더의 파생일 뿐 별도 개념 아님)

**파일 연결 (File association)**:
OS에서 .cbz/.cbr을 더블클릭하면 이 앱이 해당 파일을 여는 것. .zip은 연결하지 않는다(앱 안에서만 열 수 있다).

**읽던 위치 (Reading position)**:
파일별로 기억되는 마지막으로 읽은 페이지. 파일을 다시 열면 이 위치에서 시작한다.
_Avoid_: 북마크(사용자가 명시적으로 찍는 것이 아님)

**동작 (Action)**:
단축키로 실행되는 단위. 읽기 이동 6가지(다음/이전 페이지, 처음/마지막 페이지, 다음/이전 파일), **보기 모드 전환** 2가지(한장 보기·연속 보기), UI 동작인 **파일 패널 토글**과 **앱 종료**를 포함한다. 동작은 유효 범위가 갈린다 — 읽기 이동과 보기 모드 전환은 파일이 열려 있을 때만 동작하고, 파일 패널 토글(기본 커스텀 키 `/`)과 앱 종료(`x`)는 파일이 열려 있지 않아도(빈 화면 포함) 전역으로 동작한다. 보기 모드 전환은 왕복 토글이 아니라 목표 모드를 직접 지정하는 방식이다.
_Avoid_: 명령, 커맨드(Tauri 커맨드와 혼동), 보기 모드 토글(직접 지정이므로)

**단축키 (Keybinding)**:
동작에 매핑된 키. 각 동작은 항상 동작하는 **표준 키**(화살표·스페이스·Home·End 등, 재지정 불가)와, 사용자가 지정하는 **커스텀 키** 1개를 가진다. 커스텀 키는 조합키(Ctrl 등) 없는 단일 키다. 다음/이전 파일의 기본 커스텀 키는 `.`/`,`, 한장/연속 보기의 기본 커스텀 키는 `1`/`2`. 커스텀 키는 파일별 읽던 위치처럼 앱 상태로 영속된다. 키 외의 입력도 동작에 묶일 수 있다 — 다음/이전 파일은 **마우스 앞으로/뒤로 버튼**에도 고정으로(재지정 불가) 매핑된다.
_Avoid_: 핫키, 액셀러레이터

**히스토리 (History)**:
지금까지 연(본) 코믹 아카이브들의 목록. 파일당 한 항목이며 마지막으로 연 시각 기준 최신순으로 정렬된다(같은 파일을 다시 열면 시각만 갱신되어 맨 위로). 항목을 클릭하면 그 파일을 열고(현재 폴더도 그 파일 폴더로 이동), 항목별 삭제와 전체 리셋이 가능하다. **읽던 위치와는 다른 개념** — 읽던 위치는 파일 내 페이지, 히스토리는 파일 열람 목록이다.
_Avoid_: 최근 파일(마지막 파일 열기의 last_file와 혼동), 열람 로그(중복 허용 아님)

**파일 이어보기 (Seamless file continuation)**:
현재 파일의 마지막 페이지에서 다음으로 넘어가려 하면 현재 폴더의 다음 코믹 아카이브를 자동으로 열고, 첫 페이지에서 이전으로 넘어가려 하면 이전 아카이브(의 마지막 페이지)를 여는 기능. 한장·연속 두 보기 모드 모두에서 동작하며 옵션으로 켜고 끈다. **보기 모드(한장/연속)와는 다른 개념** — 보기 모드는 페이지 표시 방식이고, 파일 이어보기는 파일 경계를 넘는 이동이다.
_Avoid_: 연속 보기 모드(보기 모드와 혼동), 자동 넘김
