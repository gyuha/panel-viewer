# 보기 모드 완성 + 상태 기억

## Goal / Non-goals
- Goal: 우→좌 페이지 모드와 연속 스크롤 모드를 추가해 세 가지 보기 모드를 자유롭게 전환할 수 있게 하고, 읽던 위치·보기 모드·마지막 폴더를 앱 재시작 후에도 복원한다.
- Non-goals:
  - 두 쪽 스프레드, 자유 줌 (범위 밖 — part 1과 동일)
  - 파일 패널/썸네일/파일 연결 (part 3/3)
  - SQLite 등 DB 도입 — 상태는 JSON 파일로 충분

## Source of truth
- Glossary terms: 보기 모드, 읽던 위치 — `.forge/CONTEXT.md`
- Related ADRs: none
- Definition of Done: 세 모드 전환 시 현재 페이지가 유지되고, 앱을 종료했다가 같은 파일을 다시 열면 읽던 위치와 마지막 보기 모드에서 시작한다.

## Work slices
- [ ] S1. 우→좌 페이지 모드 — 내비게이션(키보드·클릭 영역) 방향 반전 — 완료 기준: 우→좌 모드에서 ← 키와 왼쪽 클릭이 다음 페이지로 이동한다
- [ ] S2. 연속 스크롤 모드 — 세로 스크롤, 폭 맞춤 고정, 가시 범위 밖 페이지 지연 로드(가상화) — 완료 기준: 100페이지 이상 아카이브를 메모리 폭증 없이 스크롤로 끝까지 읽을 수 있다
- [ ] S3. 모드 전환 UI + 페이지 동기화 — 툴바 모드 전환과 단축키, 전환 시 현재 페이지 유지 — 완료 기준: 페이지 모드 37페이지에서 연속 모드로 전환하면 37페이지 위치로 스크롤되어 있고, 역방향 전환도 동일하다 (depends: S1, S2)
- [ ] S4. 상태 기억(TDD) — 파일별 읽던 위치 + 마지막 보기 모드 + 마지막 폴더를 앱 데이터 디렉토리의 JSON으로 저장/복원 — 완료 기준: 저장/복원 로직 단위 테스트 통과 + 앱 재시작 후 같은 파일을 열면 읽던 위치·모드가 복원된다
