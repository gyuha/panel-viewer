# 파일 목록 패널 표시/숨김 토글 (아이콘 + '/' 단축키)

## Goal / Non-goals
- Goal: 왼쪽 파일 패널을 완전히 숨겼다/보였다 할 수 있게 한다. 좌상단에 항상 보이는 토글 아이콘을 두고, 키맵에 '패널 토글' 동작(기본 커스텀 키 `/`)을 추가한다. 숨김/표시 상태는 재시작 후에도 복원된다.
- Non-goals:
  - 패널을 얇은 스트립으로 접기(완전 숨김만; 숨기면 본문이 꽉 참)
  - 패널 폭 조절/리사이즈
  - 우측(뷰어) 패널 토글

## Source of truth
- Glossary terms: 동작(Action, '파일 패널 토글' 포함), 단축키(Keybinding), 파일 패널 — `.forge/CONTEXT.md`
- Related ADRs: none
- 결정 사항(그릴링 확정):
  - **아이콘 위치**: 좌상단에 항상 표시. 패널이 보이면 패널 헤더 좌상단, 숨겨지면 메인 영역 좌상단(뷰어·빈 화면 모두)에 토글 아이콘이 남아 어느 상태에서도 클릭으로 토글 가능.
  - **토글 동작**: 패널을 완전히 숨기고(레이아웃에서 제거) `app-main`이 전체 폭을 차지. 다시 토글하면 복귀.
  - **'/' 단축키**: 기존 키맵 시스템에 **'패널 토글'을 7번째 동작으로 추가**. 표준 키 없음, 기본 커스텀 키 `/`. 설정 모달에 표시되어 재지정 가능하고 충돌 검사에 포함(다른 동작이 `/`를 못 뺏음). 단, 읽기 이동과 달리 **App 전역**에서 처리되어 파일이 안 열려 있어도(빈 화면) 동작하며, 설정 모달 캡처 중엔 미발동.
  - **영속**: state.json에 패널 숨김 상태(bool) 추가. 필드 없으면(구버전) 기본값(표시)으로 로드.
- Definition of Done: (1) 좌상단 토글 아이콘 클릭으로 패널이 완전히 숨겨지고/다시 보이며, 숨김 시 본문이 꽉 찬다. (2) `/` 키로 어디서든(빈 화면 포함) 토글되고, 설정 모달 열림 중엔 발동하지 않는다. (3) 설정 모달에 '패널 토글'이 나타나 재지정 가능하며, `/`를 다른 읽기 동작에 지정하려 하면 거부된다. (4) 숨김/표시 상태가 앱 재시작 후 복원된다.
