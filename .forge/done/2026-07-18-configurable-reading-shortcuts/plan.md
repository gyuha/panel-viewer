# 설정 가능한 읽기 단축키 + 단축키 설정 모달

## Goal / Non-goals
- Goal: 6개 읽기 동작(다음/이전 페이지, 처음/마지막 페이지, 다음/이전 파일)에 사용자 지정 단축키를 붙일 수 있게 한다. 다음 파일=`.`, 이전 파일=`,`가 기본. 파일 패널의 버튼으로 여는 모달에서 각 동작의 커스텀 키를 보고 바꾸며, 설정은 앱 재시작 후에도 유지된다.
- Non-goals:
  - 조합키(Ctrl/Cmd/Shift+키) 단축키 — 커스텀 키는 조합 없는 단일 키만
  - 닫기(Esc)·보기모드 전환의 재지정 — 재지정 대상은 위 6개 동작뿐
  - 표준 키(화살표·스페이스·PageUp/Down·Home·End) 재지정/제거 — 항상 고정으로 동작
  - 프리셋/프로필, 여러 키 바인딩(동작당 커스텀 키는 1개)

## Source of truth
- Glossary terms: 동작(Action), 단축키(Keybinding), 보기 모드 — `.forge/CONTEXT.md`
- Related ADRs: none
- 결정 사항(그릴링 확정):
  - **키 모델**: 각 동작 = 항상 동작하는 표준 키(고정) + 커스텀 키 1개. 페이지/처음/마지막 동작의 커스텀 키 기본값은 없음(표준 키가 이미 커버), 다음 파일=`.`·이전 파일=`,`.
  - **파일 이동 키는 한장·연속 두 모드 모두**, 파일이 열려 있을 때 동작. 페이지 이동 키는 페이지(한장) 모드에서만.
  - **모달 입력(키 캡처) 중에는 단축키 미발동.** 커스텀 키 지정은 행 클릭 → 키 한 번 누름으로 캡처.
  - **충돌 처리**: 지정하려는 키가 다른 동작의 커스텀 키 또는 표준 키와 겹치면 거부하고 "그 키는 X에 사용 중" 안내.
  - **모달에 "기본값 복원"** 포함.
  - **영속**: 상태 저장(state.json)에 동작→커스텀 키 맵을 추가. 필드 없으면(구버전) 기본값으로 로드.
- Definition of Done: (1) 파일을 연 상태에서 `,`/`.`로 이전/다음 파일 이동이 한장·연속 두 모드 모두 동작한다. (2) 파일 패널의 버튼으로 모달이 열려 6개 동작의 표준 키와 커스텀 키가 보이고, 커스텀 키를 단일 키로 바꿀 수 있으며 충돌 시 거부·안내한다. (3) 기존 표준 키(화살표·스페이스 등)는 그대로 동작한다. (4) 변경한 커스텀 키가 앱 재시작 후에도 유지된다. (5) 기본값 복원이 동작한다.
