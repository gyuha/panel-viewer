# 상위 폴더로 이동하면 방금 떠난 폴더로 파일 패널 스크롤 복원

## 목표 / 비목표
- 목표: 파일 패널에서 "상위 폴더"로 올라갈 때, 방금 떠나온 하위 폴더 행을 새 목록에서 찾아 **세로 가운데로 스크롤**하고 **하이라이트**한다. 지금은 목록이 교체되면 항상 맨 위에서 시작한다(`App.tsx` `navigate`가 `listing`을 통째로 교체, `.panel-list`는 스크롤을 건드리지 않음).
- 동작 규칙(그릴링에서 합의):
  - 대상 = **방금 떠난 하위 폴더**(올라오기 직전의 현재 폴더). 새 목록의 폴더 행을 **파일명 NFC 정규화 비교**(`lib/folder.ts` 방식)로 찾는다 — macOS에서 경로가 NFC/NFD로 달라도 매칭되도록.
  - 정렬 = 가운데 정렬. 하이라이트 = 파일 행 `.active`(`--primary` 배경)와 **구분되는 은은한 톤**(`--surface-strong` 계열 배경/테두리).
  - 하이라이트 수명 = **다음 이동이 일어날 때까지 유지**(폴더 클릭·파일 열기·상위 폴더 이동 시 지움). 타이머/페이드 없음.
  - 새 목록에서 대상 폴더를 못 찾으면(삭제·이름 변경 등) 하이라이트 없이 현재 동작(맨 위) 유지.
- 비목표:
  - 하위 폴더로 들어가는 이동, 히스토리·파일 연결로 폴더가 바뀔 때의 **열린 파일(active) 행 스크롤**은 이번에 다루지 않는다(현재 동작 유지). 필요하면 별도 작업.
  - 타이머 기반 하이라이트, 새 설정 항목, 새 단축키 없음.

## 기준 문서
- 용어: `.forge/CONTEXT.md`의 **파일 패널**, **현재 폴더**, **복귀 폴더 표시**(이번 그릴링에서 추가)
- 관련 ADR: 없음
- 완료 정의(DoD):
  1. `npx vitest run src/lib/folder.test.ts` 통과 — 새 순수 함수 테스트가 구현 전에는 **실패(red)**, 구현 후 통과(green). NFC/NFD 이름 매칭, 대상 없음(→ 없음 반환) 케이스 포함.
  2. `task check`(= `tsc --noEmit` + `cargo check`) 통과.
  3. `task test` 전체 통과.
  4. **수동(`task dev`, GUI는 자동 테스트 불가)**: 하위 폴더가 많아 스크롤이 생기는 폴더 트리에서 (a) 깊이 들어간 뒤 "상위 폴더"로 올라오면 떠난 폴더가 패널 세로 가운데에 보이고 하이라이트된다, (b) 그 상태에서 다른 폴더를 클릭/파일을 열면 하이라이트가 사라진다, (c) 하위 폴더 진입 시에는 이전처럼 맨 위에서 시작한다, (d) 한글(NFD) 폴더명에서도 동작한다.
  - 사전 상태(작성 시점 실행): `npx vitest run src/lib/folder.test.ts` → 4 passed, `npx tsc --noEmit` → exit 0. 둘 다 **회귀 방지(regression guard)** 성격이라 이미 통과가 정상이다. DoD 1의 "새 테스트 red"는 아직 존재하지 않는 테스트이므로 구현 슬라이스에서 추가·확인한다. DoD 4는 기계 검증이 불가능해 위 수동 확인이 면제 사유다(GUI 렌더링·스크롤은 macOS Tauri E2E가 없음).
