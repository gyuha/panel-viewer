# 파일 패널 + 커버 썸네일 + OS 파일 연결

## Goal / Non-goals
- Goal: 왼쪽 파일 패널에서 폴더를 오가며 코믹 아카이브를 골라 읽을 수 있게 하고(클릭 즉시 뷰어에서 열림, 커버 썸네일 표시), Finder에서 .cbz/.cbr 더블클릭으로 앱이 해당 파일을 열게 한다.
- Non-goals:
  - 폴더 트리 표시 — 패널은 현재 폴더의 평평한 목록만 (그릴링에서 확정)
  - .zip 파일 연결 — 범용 포맷이라 제외, 앱 안에서만 열기
  - 별도 미리보기 패널 — 파일 클릭 = 뷰어에서 즉시 열기
  - Windows/Linux 파일 연결 검증 — macOS 우선

## Source of truth
- Glossary terms: 파일 패널, 미리보기, 커버, 파일 연결 — `.forge/CONTEXT.md`
- Related ADRs: none
- 디자인: 패널은 DESIGN.md의 크림 캔버스 + 헤어라인 구분선, 선택 항목 강조는 Cursor Orange를 절제해 사용.
- Definition of Done: 파일 패널만으로 폴더 이동·파일 열기가 가능하고 목록에 커버 썸네일이 뜨며, Finder에서 .cbz 더블클릭 시 (번들 빌드된) 앱이 그 파일을 연 상태로 실행된다.

## Work slices
- [ ] S1. 폴더 읽기 커맨드(TDD) — 지정 폴더의 하위 폴더 + 코믹 아카이브(cbz/cbr/zip) 목록을 자연 정렬로 반환하는 Tauri 커맨드 — 완료 기준: 픽스처 디렉토리로 필터링·정렬을 검증하는 `cargo test`가 통과한다
- [ ] S2. 파일 패널 UI — 왼쪽 패널에 상위 폴더(..)·하위 폴더·파일의 평평한 목록, 폴더 클릭 시 이동, 파일 클릭 시 뷰어에서 즉시 열림, 현재 폴더 경로 표시 — 완료 기준: 패널만으로 폴더 탐색과 파일 열기가 가능하고 현재 읽는 파일이 목록에서 강조된다 (depends: S1)
- [ ] S3. 커버 썸네일 — 목록 항목에 커버(첫 페이지) 썸네일을 지연 추출·리사이즈해 표시, 디스크 캐시로 재방문 시 즉시 로드 — 완료 기준: 파일 수십 개 폴더에서 UI 블로킹 없이 썸네일이 채워지고, 두 번째 방문부터는 캐시에서 즉시 뜬다 (depends: S2)
- [ ] S4. OS 파일 연결 — Tauri 설정에 .cbz/.cbr fileAssociations 등록, 앱 시작 인자·실행 중 열기 이벤트 처리 — 완료 기준: macOS 번들 빌드 후 Finder에서 .cbz 더블클릭 시 앱이 해당 파일을 연다 (앱 실행 중일 때도 동일)
